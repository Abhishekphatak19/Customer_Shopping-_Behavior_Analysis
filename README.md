## 📌 Project Overview

This project focuses on analyzing **customer shopping behavior** to uncover insights related to revenue, customer segmentation, and purchasing trends.

The project demonstrates an **end-to-end workflow**:
➡️ Data Cleaning → SQL Analysis → Interactive Dashboard

---

## 🧰 Tech Stack

| Tool                | Usage                         |
| ------------------- | ----------------------------- |
| 🐍 Python           | Data Cleaning & Preprocessing |
| 🗄️ SQL             | Business Query Analysis       |
| 📊 Power BI         | Dashboard & Visualization     |
| 📓 Jupyter Notebook | Exploration                   |
